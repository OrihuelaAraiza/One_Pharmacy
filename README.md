# One Pharmacy

Experiencia web funcional en React para One Pharmacy, basada en el prototipo original.

Incluye catálogo con precios por sucursal, búsqueda y filtros, carrito, cuentas de paciente y médico, descuento profesional, puntos, checkout, historial de pedidos y paneles de sucursal y Dirección General.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run build
npm test
```
